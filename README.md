# مغيّر الأيدي (ID Changer) - أندرويد

نسخة أندرويد كاملة من أداة Windows "Golden Crad ID Changer" لتعديل سوفت وير ريسيفرات Sunplus.

## الوظايف
- محرر أيدي 1506 بأوفسيتات ثابتة (كستمر/بورد/ماك/سيريال/ريجون/هيدر + مخصص)
- أدوات فانيلا: كشف الأيدي بتوقيع BIN_0S أو SPHE في أي سوفت، نسخ الأيدي، نسخ بلوك SPHE 256 بايت، إصلاح CRC فقط
- إصلاح SPHE CRC-32/MPEG-2 (بولي 0x04C11DB7، قيمة ابتدائية 0xFFFFFFFF، بدون انعكاس، بدون XOR نهائي، مخزن little-endian عند +0xFC)
- عارض هيكس، بحث هيكس/نص، مقارنة ملفين بايت-بايت مع XOR
- قائمة باتشات جماعية مع بروفايل JSON بنفس صيغة نسخة الويندوز
- حفظ آمن: نسخة احتياطية بتاريخ ووقت + تحقق بايت-بايت
- هاشات MD5/SHA-1/SHA-256/CRC-32

واجهة عربية كاملة ومتوافقة مع TalkBack. بدون إنترنت وبدون أي صلاحيات شبكة.

## البناء
GitHub Actions (`.github/workflows/build.yml`) يبني APK غير موقّع (release, unsigned) ويرفعه كـ artifact وفي صفحة Releases.
